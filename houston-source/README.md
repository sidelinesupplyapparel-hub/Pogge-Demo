# Threadmark Houston

The built public page is served from `/Pogge-Demo/houston/`. The root golf site is separate.

## Build

From this directory, run `npm install` then `npm run build`. Commit `houston-source` and the updated `../houston/_app` and `../houston/index.html` files. `../houston/assets` contains the original photos and brand graphics used by the page; the build preserves them.

Connection and memories are demonstration features saved in the visitor’s browser, not a shared ownership registry. See SOURCES.md for content and image sources.
